This is an easy to use search tool for excel that helps to search for specific words in a column of a table separated with '|' character.
it is useful for older office versions like 2013 and 2016.
here is a video on how to use it: [https://youtu.be/AqYWBayh3nw](https://youtu.be/AqYWBayh3nw)

NB: the AddIn needs .NET Framework 4.8 to be installed.
