This is a simple and user-friendly Excel search tool that allows you to find specific keywords within a table column. You can enter multiple keywords separated by the ‘|’ character, and the tool will search for all matching entries.

It is especially useful for older Microsoft Office versions such as 2013 and 2016.

Here is a video demonstrating how to use it: https: //youtu.be/AqYWBayh3nw

Note: The Add-In requires the .NET Framework 4.8 to be installed.
